# Segurança e privacidade

Não publique neste projeto chaves privadas, senhas, tokens, endereços IP residenciais, dumps do Fire TV, saves ou ROMs comerciais. Se encontrar um problema de segurança, abra uma issue sem anexar dados sensíveis e descreva apenas os passos mínimos para reproduzir.

Antes de compartilhar uma captura, oculte nomes de usuário, endereços, notificações e identificadores do dispositivo.
