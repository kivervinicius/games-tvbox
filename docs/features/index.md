## Escopo atual

O produto usa GitHub Releases como armazenamento remoto opcional da biblioteca privada. Não há banco ou servidor próprio; o Manager publica o manifesto e o launcher consulta o GitHub diretamente. O RetroArch continua sendo a dependência externa que executa o conteúdo.
