# Catálogo de jogos

## Adicionar seu acervo

Escolha a pasta raiz no Manager. Ele cria um catálogo local a partir de arquivos encontrados e mantém a biblioteca original sem mover ou apagar arquivos.

## Plataformas suportadas

O catálogo de exemplo cobre NES, SNES, Mega Drive, GBA e PlayStation. Cada item associa nome, caminho, plataforma, core e imagem de capa.

## Capas ausentes

Quando uma capa não existe, o launcher exibe um cartão legível com o nome do jogo. Para adicionar uma capa, use `Slides e aparência` no Manager ou coloque um asset com nome compatível no projeto Android.
