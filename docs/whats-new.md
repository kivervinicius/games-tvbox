# O que há de novo

## Primeira distribuição pública

O projeto agora pode ser clonado sem carregar ROMs, saves ou configurações pessoais. A documentação separa o caminho rápido do usuário, o build para desenvolvedores e o diagnóstico operacional.

O tema padrão é genérico; a personalização de imagens e textos continua disponível no Manager para cada instalação local.
