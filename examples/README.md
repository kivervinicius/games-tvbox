# Exemplos de configuração

Copie o exemplo desejado para uma pasta de trabalho e substitua os valores entre `<...>` pelos caminhos do seu computador ou dispositivo. Os arquivos desta pasta não apontam para nenhum endereço, ROM ou conta real.

- `catalog.example.json`: catálogo que o launcher lê.
- `theme/slides.example.json`: carrossel visual do launcher.
- `controller-profile.example.cfg`: ponto de partida para o perfil do RetroArch.
